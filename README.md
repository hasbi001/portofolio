# Next.js Portfolio Template

Modern dark portfolio template built with Next.js App Router, React, Tailwind CSS and Lucide icons.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Customize

Edit `app/page.jsx`:
- Name and title
- About
- Skills
- Projects
- Experience
- Contact email

Edit `components/Navbar.jsx` for social links.

Put your CV at `public/cv.pdf`.

## Production

```bash
npm run build
npm start
```
